Mini-CRM en 60 secondes

Clients et contrats réunis dans un seul espace, échéances repérées 30 jours à l'avance, chaque modification consignée automatiquement. Le son est activé : la musique a été composée pour la vidéo.

Voir le projet sur GitHub Voir les écrans de l'application Télécharger la musique (MP3)

Vidéo composée en HTML et CSS, animée image par image (1 800 images capturées par Chrome sans interface), sur une musique originale synthétisée par le code (numpy) : aucun extrait, aucun échantillon, aucune banque d'images, donc aucun droit tiers. Polices Instrument Serif et Plus Jakarta Sans (SIL Open Font License), icônes Bootstrap Icons (MIT). Conçu et développé par Dibie Elisee Jules Cedric KOUADIO.
